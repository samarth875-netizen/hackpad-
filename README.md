# hackpad
This is a hackpad I created. It includes three keys, a rotary knob, and a small OLED screen. I have not added any code for it because I am making it customizable so that a person can write code for it by himself. for specifically his purposes 
<img width="850" height="504" alt="image" src="https://github.com/user-attachments/assets/928a3468-5521-4d36-9d99-5c19be3a768c" />       
 
 This pad was created using the xiao Seed Studio Zao and with the help of three mechanical keys, one rotary encoder, and one OLED screen. This is a basic, micro pad I created as my first PCB project.

I have edited the PCB files and the CAD files. In the repository, the CAD files include the bottom case and the upper lid, and they can be screwed together using 3 mm screws. I have not added threads, as you can directly screw the screw into the holes, and that's all.

I have attached a screenshot which includes the position of each button so that you can code by yourself. And I have not used diodes, as the seed zao doesn't need diodes until I am using a matrix. I have not used a matrix, as I have only used three keys, so I have not used a diode.
